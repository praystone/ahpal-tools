📄 PDF 合併工具

合併多個 PDF 檔案，完全在瀏覽器內處理，檔案不上傳，隱私零風險。

✅ 完全離線：所有處理都在你的瀏覽器完成，不會上傳任何檔案到伺服器。
（選擇 PDF 後，按「合併 PDF」）

📚 為什麼 PDF 合併不要在網路上做？給門外漢的完整說明

你可能用過「ILovePDF」「SmallPDF」這類線上 PDF 工具。它們很方便，但有一個問題：你的 PDF 會被上傳到別人的伺服器。

一、一句話講完

線上 PDF 工具 = 上傳你的檔案到境外伺服器 = 你的合約、身分證、病歷可能被看到。

本工具用「純前端」技術，PDF 在你的瀏覽器內處理，完全不上傳。

二、線上 PDF 工具的 3 個風險

風險說明
隱私外洩檔案上傳到別人伺服器，對方能看、能存、能備份
檔案大小限制免費版通常限 10MB~50MB，超過要付費
廣告干擾免費工具塞滿廣告，體驗差

三、純前端 PDF 合併的原理

本工具用開源的 pdf-lib（JavaScript 函式庫），在瀏覽器內：

  1. 讀取你選的 PDF 檔案（用 FileReader，不上傳）
  2. 用 pdf-lib 解析 PDF 結構
  3. 把多個 PDF 合併成一個
  4. 產生新的 PDF 讓你下載

全程在你的瀏覽器內完成，沒有任何資料離開你的電腦。

四、純前端 vs 線上的比較

項目本工具（純前端）ILovePDF 等（線上）
隱私✅ 檔案不上傳❌ 檔案上傳到境外
檔案大小✅ 只受記憶體限制❌ 免費版限 10~50MB
廣告✅ 零廣告❌ 一堆廣告
速度✅ 即時❌ 要等上傳下載
離線✅ 可離線使用❌ 要連網

五、PDF 合併的實際用途

  • 合約：把多份合約合併成一個 PDF
  • 報告：把多個章節合併成完整報告
  • 掃描：把多張掃描合併成一個 PDF
  • 履歷：把履歷和作品集合併
  • 發票：把多張發票合併報帳

六、常見誤解

  • ❌ 誤解：線上工具比較快。
    ✅ 事實：純前端不用上傳下載，通常更快。
  • ❌ 誤解：線上工具比較安全。
    ✅ 事實：純前端不上傳，才安全。
  • ❌ 誤解：純前端不能處理大檔案。
    ✅ 事實：只受記憶體限制，一般電腦可處理 100MB+。
  • ❌ 誤解：純前端功能比較少。
    ✅ 事實：合併、分割、壓縮都能做。
  • ❌ 誤解：PDF 合併會改變內容。
    ✅ 事實：合併只合併頁面，不改變內容。

七、這個工具能幫你做什麼？

  • 合併多個 PDF：選多個 PDF，合併成一個
  • 調整順序：用上下按鈕調整 PDF 順序
  • 完全離線：檔案不上傳，隱私零風險
  • 免費、無廣告：不用註冊、不用付費

❓ 常見問題（FAQ）

PDF 合併工具是什麼？
PDF 合併工具是把「多個 PDF」合併成「一個 PDF」的工具。
合併會損失畫質嗎？
不會。PDF 合併是「頁面拼接」，不重新壓縮，畫質不變。
這個工具會上傳我的 PDF 嗎？
不會。所有合併都在你的瀏覽器完成，不上傳任何資料，隱私零風險。
支援加密的 PDF 嗎？
不支援。加密的 PDF 需先解密，才能合併。
合併後檔案變多大？
約等於「所有 PDF 檔案大小總和」，因為是頁面拼接，不重新壓縮。
