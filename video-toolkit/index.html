三、怎麼用

  1. 複製上面的指令
  2. 打開終端機（Windows：PowerShell / CMD；Mac：Terminal）
  3. cd 到影片所在資料夾
  4. 貼上指令，按 Enter
  5. 等 ffmpeg 跑完，輸出檔就在同一資料夾
📌 需要先安裝 ffmpeg。Windows 可用 winget install ffmpeg；Mac 可用 brew install ffmpeg。
