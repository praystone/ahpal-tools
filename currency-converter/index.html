手動輸入匯率，換算多國貨幣。純前端、完全離線。

📚 匯率換算器是什麼？給門外漢的完整說明

你要去日本玩，換日圓；你要買美國網站的东西，看美元；你要匯款給大陸朋友，算人民幣。這些都需要「匯率換算」。這篇文章一次講清楚。

一、一句話講完

匯率換算器 = 把「一種貨幣」換成「另一種貨幣」的工具。

本工具用「手動輸入匯率」，因為各銀行匯率不同，手動輸入最準。

二、匯率是什麼？

匯率是「兩種貨幣的交換比例」。例如「1 美元 = 31.5 新台幣」，就是 USD/TWD = 31.5。

三、為什麼不用即時匯率？

  • 各銀行匯率不同：台銀、玉山、國泰的匯率都不一樣。
  • 現鈔 vs 即期：現鈔匯率較差，即期匯率較好。
  • 手續費：換匯有手續費，即時匯率不包含。
  • API 限制：免費 API 有次數限制，不穩定。

六、常見誤解

  • ❌ 誤解：匯率是固定的。
    ✅ 事實：匯率每天變動，甚至每分鐘變動。
  • ❌ 誤解：各銀行匯率一樣。
    ✅ 事實：各銀行匯率不同，差距可達 1~2%。
  • ❌ 誤解：現鈔和即期匯率一樣。
    ✅ 事實：現鈔匯率較差（銀行要承擔保管成本）。
  • ❌ 誤解：換匯不用手續費。
    ✅ 事實：換匯有手續費，通常藏在匯率裡。
  • ❌ 誤解：即時匯率最準。
    ✅ 事實：即時匯率是「中間價」，實際換匯會加減碼。

八、常見問題（FAQ）

❓ 常見問題（FAQ）

匯率換算器是什麼？
匯率換算器是換算「不同貨幣」的工具。手動輸入匯率，即可換算多國貨幣。
為什麼不用即時匯率？
因為即時匯率需要 API，且各銀行匯率不同（現鈔、即期、刷卡）。手動輸入你查到的匯率，最準。
匯率怎麼查？
查台灣銀行、玉山銀行、國泰世華的「牌告匯率」，或 Google「USD to TWD」。
現鈔匯率和即期匯率差在哪？
現鈔匯率是「拿現金換」，匯率較差；即期匯率是「帳戶轉帳」，匯率較好。
這個工具會上傳我的資料嗎？
不會。所有換算都在你的瀏覽器完成，不上傳任何資料。
