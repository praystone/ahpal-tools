📚 QR Code 是什麼？給門外漢的完整說明

你掃過 QR Code 嗎？那個黑白方塊，藏著一個網址、一段文字，甚至一張名片。這篇文章一次講清楚。

一、一句話講完

QR Code = Quick Response Code（快速響應碼）= 一種「二維條碼」，能儲存比條碼更多資料。

它 1994 年由日本 Denso Wave 公司發明，原本是為了追蹤汽車零件。

二、為什麼叫「二維」條碼？

傳統條碼（一維條碼）只有「橫向」資料，只能存 20 個數字。QR Code 是「二維」的，橫向 + 縱向都有資料，能存 7,089 個數字或 4,296 個英文字元。

三、QR Code 的 3 個定位點

你注意過 QR Code 角落有 3 個「回」字型方塊嗎？那是「定位點」，讓掃描器知道「這是 QR Code、方向是什麼」。

  • 左上角：定位點
  • 右上角：定位點
  • 左下角：定位點

3 個定位點讓掃描器「無論正反、旋轉、傾斜」都能正確讀取。

四、QR Code 的「容錯機制」

QR Code 有 4 種容錯等級（L、M、Q、H），代表「即使部分損壞，仍能讀取」的能力。

等級容錯率適用情境
L（Low）7%乾淨環境、小尺寸
M（Medium）15%一般環境（預設）
Q（Quartile）25%工業環境、易損壞
H（High）30%戶外、易磨損

容錯率越高，QR Code 越「密」，但越「耐損」。例如 H 等級的 QR Code，即使被遮住 30%，還是能讀取。

五、QR Code 的實際用途

  • 網址：掃了直接開網站
  • 名片：掃了直接加聯絡人
  • Wi-Fi：掃了自動連 Wi-Fi
  • 付款：掃了直接付款（LINE Pay、街口）
  • 實名制：掃了填資料（疫情期間常用）
  • 菜單：掃了看菜單（餐廳常用）

六、QR Code 的 3 個限制

限制 1：容量有限

QR Code 最多存 7,089 個數字或 4,296 個英文字元。要存大檔案（如影片），不行。

限制 2：尺寸有限

QR Code 太小（如小於 1 公分），掃描器讀不到。太大（如大於 1 公尺），也難掃。

限制 3：安全風險

QR Code 可能被貼上惡意網址。掃描前要看清楚「掃了會去哪裡」。

七、常見誤解

  • ❌ 誤解：QR Code 只能用來開網址。
    ✅ 事實：QR Code 能存文字、網址、名片、Wi-Fi、付款資訊。
  • ❌ 誤解：QR Code 容量無限。
    ✅ 事實：最多 7,089 個數字或 4,296 個英文字元。
  • ❌ 誤解：QR Code 損壞就不能讀。
    ✅ 事實：有容錯機制，損壞 30% 仍可讀。
  • ❌ 誤解：QR Code 一定安全。
    ✅ 事實：可能被貼上惡意網址，掃描前要確認。
  • ❌ 誤解：QR Code 只能黑白。
    ✅ 事實：可以彩色，但對比度要夠。
