🔍 JSON 對帳器

上傳分類 JSON 與實體檔名清單，即時檢查幽靈登記、未登記實體、關鍵字重複。純前端，不上傳。

💡 純前端對帳，不上傳任何資料。判斷邏輯同 check-category.py。
（按「開始對帳」後，結果會出現在這裡）

❓ 常見問題（FAQ）

JSON 對帳器是什麼？
JSON 對帳器是檢查「JSON 登記」與「實體檔名清單」是否一致的工具。
什麼是幽靈登記？
幽靈登記是「JSON 有、實體無」的文章。通常是生成失敗，但 JSON 已寫入。
什麼是未登記實體？
未登記實體是「實體有、JSON 無」的文章。通常是手動新增，但忘了更新 JSON。
這個工具會上傳我的檔案嗎？
不會。所有檢查都在你的瀏覽器完成，不上傳任何資料。
為什麼要對帳？
因為「JSON 總數 = 實體總數」不代表「每一筆都對得上」。可能有幽靈、未登記、重複。
