📚 二維碼掃描器是什麼？給門外漢的完整說明

你收到一張 QR Code 圖片，但手機掃不到；你截圖了一張 QR Code，想解出網址。這就是「二維碼掃描器」。這篇文章一次講清楚。

一、一句話講完

二維碼掃描器 = 把「QR Code 圖片」解碼成「文字或網址」。

純前端處理、完全離線、不上傳。

二、QR Code 是什麼？

QR Code（Quick Response Code）是 1994 年由日本 Denso Wave 發明的「二維條碼」。它能儲存網址、文字、名片、Wi-Fi 等資訊。

三、QR Code 的三個定位點

QR Code 角落有 3 個「回」字型方塊，是「定位點」，讓掃描器知道「這是 QR Code、方向是什麼」。

四、怎麼用？

1. 選 QR Code 圖片（PNG、JPG）
2. 自動解碼
3. 複製結果

五、為什麼掃不出來？

  • 圖片模糊：拍照手震、壓縮過度。
  • QR Code 太小：小於 100×100 像素。
  • 對比度不足：灰底灰字、深底深字。
  • QR Code 損壞：被遮擋、破損。
  • 不是 QR Code：可能是條碼、Data Matrix。

六、常見誤解

  • ❌ 誤解：QR Code 只能用來開網址。
    ✅ 事實：QR Code 能存文字、名片、Wi-Fi、付款資訊。
  • ❌ 誤解：所有 QR Code 都一樣。
    ✅ 事實：QR Code 有不同容錯等級（L、M、Q、H）。
  • ❌ 誤解：掃描器一定成功。
    ✅ 事實：圖片模糊、損壞、對比不足都會失敗。
  • ❌ 誤解：掃描器會上傳圖片。
    ✅ 事實：本工具純前端處理，不上傳。
  • ❌ 誤解：QR Code 是安全的。
    ✅ 事實：可能被貼上惡意網址，掃描前要看清楚。

七、這個工具能幫你做什麼？

  • 解碼 QR Code：上傳圖片，自動解出文字
  • 一鍵複製：複製結果
  • 完全離線：不上傳任何資料

八、常見問題（FAQ）

❓ 常見問題（FAQ）

二維碼掃描器是什麼？
二維碼掃描器是把「QR Code 圖片」解碼成「文字或網址」的工具。
支援哪些圖片格式？
支援 PNG、JPG、WebP、GIF（依瀏覽器支援）。
這個工具會上傳我的圖片嗎？
不會。所有解碼都在你的瀏覽器完成，不上傳任何資料。
為什麼掃不出來？
可能原因：圖片模糊、QR Code 太小、對比度不足、QR Code 損壞。
支援多個 QR Code 嗎？
一次解碼一個，若圖片有多個 QR Code，只會解出第一個。
