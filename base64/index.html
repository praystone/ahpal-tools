📚 什麼是 Base64？給門外漢的完整說明

你可能看過這種東西：SGVsbG8gV29ybGQ=。這就是 Base64。很多人以為它是「加密」，其實不是。

一、Base64 是什麼？一句話講完

Base64 = 把「二進位資料」轉成「64 種可列印字元」的編碼方式。

它不是加密，是「編碼」。任何人都能解碼，它只是讓「二進位資料」變成「純文字」。

二、為什麼需要 Base64？

因為「某些通道只能傳純文字」，不能傳二進位資料。

  • Email：早期 Email 只能傳 ASCII，不能傳圖片
  • JSON：JSON 只能存文字，不能存二進位
  • URL：URL 只能包含特定字元
  • HTML：HTML 屬性只能放文字

Base64 把「二進位」轉成「64 種字元」（A-Z、a-z、0-9、+、/），就能放進這些通道。

三、Base64 的 64 種字元

範圍字元數量
大寫字母A-Z26
小寫字母a-z26
數字0-910
符號+、/2
填充=（不是字元，是填充）

26 + 26 + 10 + 2 = 64，所以叫「Base64」。

四、Base64 的 3 個常見誤解

誤解 1：Base64 是加密

錯。Base64 不是加密，它是「編碼」。任何人都能解碼，沒有密鑰。

誤解 2：Base64 會讓資料變小

錯。Base64 會讓資料變「大」（約 1.33 倍）。因為 3 bytes 變 4 字元。

誤解 3：Base64 能保護密碼

錯。Base64 只是編碼，不是加密。密碼要用「雜湊（hash）」或「加密（encryption）」，不是 Base64。

五、Base64 的實際用途

  • 圖片嵌入 HTML：<img src="data:image/png;base64,...">
  • Email 附件：Email 附件用 Base64 編碼
  • JWT Token：JWT 的 header 和 payload 用 Base64 編碼
  • API 認證：HTTP Basic Auth 用 Base64 編碼「帳號:密碼」
  • 資料 URI：data:text/plain;base64,...

六、Base64 vs 加密：有什麼不同？

項目Base64加密（如 AES）
目的編碼（讓二進位變文字）保護（讓別人看不懂）
密鑰沒有有
可逆是（任何人都能解）是（但要密鑰）
安全性零（不是安全機制）高（保護資料）

七、常見誤解

  • ❌ 誤解：Base64 是加密。
    ✅ 事實：Base64 是編碼，不是加密。
  • ❌ 誤解：Base64 能保護密碼。
    ✅ 事實：Base64 不能保護密碼，密碼要用雜湊或加密。
  • ❌ 誤解：Base64 會讓檔案變小。
    ✅ 事實：Base64 會讓檔案變大（約 1.33 倍）。
  • ❌ 誤解：Base64 只能用來傳圖片。
    ✅ 事實：Base64 可以用來傳任何二進位資料。
  • ❌ 誤解：Base64 解碼後一定是文字。
    ✅ 事實：Base64 解碼後可能是二進位（圖片、PDF、ZIP）。

八、這個工具能幫你做什麼？

  • 編碼：把文字轉成 Base64（例如傳給 API）
  • 解碼：把 Base64 轉回文字（例如看 JWT 內容）
  • 支援 UTF-8：中文也能正確編碼解碼
