📚 CSV ↔ JSON 轉換是什麼？給門外漢的完整說明

你從 Excel 匯出一張表，想丟進程式；你從 API 拿到 JSON，想丟進 Excel。這就是「CSV ↔ JSON 轉換」。這篇文章一次講清楚。

一、一句話講完

CSV ↔ JSON 轉換 = 把「表格」與「資料格式」互相轉換。

CSV 適合人看，JSON 適合程式讀。

二、CSV 是什麼？

CSV（Comma-Separated Values）是用「逗號」分隔的純文字表格。Excel、Google Sheets、Numbers 都能開。

name,age,city
Alice,30,Taipei
Bob,25,Tokyo

三、JSON 是什麼？

JSON（JavaScript Object Notation）是輕量資料格式，用 { }、[ ] 表示物件、陣列。

[
  {"name": "Alice", "age": 30, "city": "Taipei"},
  {"name": "Bob", "age": 25, "city": "Tokyo"}
]

四、CSV vs JSON 對照

項目CSVJSON
格式純文字表格結構化資料
適合人看、Excel程式讀、API
巢狀不支援支援
資料型別全部是字串數字、字串、布林、陣列、物件

五、怎麼用？

1. 選模式（CSV→JSON 或 JSON→CSV）
2. 貼上資料
3. 按「轉換」
4. 複製結果

六、常見誤解

  • ❌ 誤解：CSV 只能用逗號。
    ✅ 事實：CSV 可以用分號、Tab（TSV）。
  • ❌ 誤解：JSON 一定比 CSV 大。
    ✅ 事實：JSON 有結構，可能比 CSV 大，也可能小。
  • ❌ 誤解：CSV 不能有巢狀資料。
    ✅ 事實：CSV 不支援巢狀，巢狀資料要攤平。
  • ❌ 誤解：JSON 只能給程式讀。
    ✅ 事實：JSON 也能給人讀（格式化後）。
  • ❌ 誤解：轉換會損失資料。
    ✅ 事實：基本轉換不損失，但巢狀資料可能攤平。

七、這個工具能幫你做什麼？

  • CSV → JSON：貼上 CSV，得到 JSON
  • JSON → CSV：貼上 JSON，得到 CSV
  • 一鍵複製：複製結果
  • 完全離線：不上傳任何資料
