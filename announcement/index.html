❓ 常見問題（FAQ）

公告欄發布器是什麼？
公告欄發布器是產生「公告發布 PowerShell 指令」的工具。它不實際發送，只產出指令，讓你複製到終端機執行。
為什麼要用這個工具？
因為手寫 PowerShell 指令容易出錯（跳脫、引號、Token）。這個工具幫你組好，你只要複製貼上。
這個工具會發送公告嗎？
不會。它是「唯讀預覽」，只產出指令，不連線、不發送。實際發送要你自己貼到終端機。
公告格式要注意什麼？
每行「文字 + 空格 + 網址」，不支援 Markdown、HTML。網址後面不要有標點，否則 linkify() 會失敗。
Token 放哪裡？
Token 只放 .env（ADMIN_TOKEN），不寫進前端、不貼對話、不進 git。
