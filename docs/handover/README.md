## 三、SOP（怎麼做）

### 新增工具 SOP

1. 複製 `_template/index.html`，改 title、h1、JS
2. 首頁加卡片：`<a href="/新slug/" class="tool-card" data-cat="...">`
3. 更新 sitemap.xml（重建，不累加）
4. 驗證七件套，缺一不 push

### 五個坑

1. **坑 1**：f-string 裡的 JSON-LD 用 `{{...}}` 寫 dict → 先在 f-string 外 `json.dumps()` 算好
2. **坑 2**：麵包屑沒 `class="breadcrumb"` → 用 `<nav class="breadcrumb" aria-label="breadcrumb">`
3. **坑 3**：Python 字串被截斷 → 寫長區塊先確認三引號閉合
4. **坑 4**：驗證器 regex 抓錯 → 用 `<loc>([^<]*)</loc>`，不抓裸 URL
5. **坑 5**：首頁用「補丁」修 → 改用「重建」，從目錄重新產生

### 一條龍範本

用 `@'...'@` here-string 包純文字 Python，寫檔 → 執行 → 清理，一段跑完。
詳見 `ahpal-static/docs/handover/ONE-DRAGON-SOP.md`。
