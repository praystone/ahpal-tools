  二、4 個工具
────────────────────────────────────────────────────────────

  1. html-editor      視覺化 HTML 編輯器（CodeMirror + html2canvas，逆向工程）

  2. 📋 匯出螢光重點：掃 span[background:#D4AF37]，輸出 markdown 清單
  3. 🧹 複製乾淨版：移除 contenteditable、螢光 span、編輯器 style

  六、6 個坑（給下一個 AI）
────────────────────────────────────────────────────────────

  1. here-string 在互動模式被 >> 干擾 → 改用 Python .py
  2. 字元數 ≠ 位元組數（中文 1 字元 = 3 bytes）
  3. git add 後 LF→CRLF 警告 → 正常
  4. Cloudflare CDN 快取 → push 後等 30~60 秒
  5. 預覽區背景黑色跟頂部融合 → 改淺灰 #e9ecef
  6. Python 字串裡不要放 triple backtick → 用 ~~~ 或 lines = [...]
